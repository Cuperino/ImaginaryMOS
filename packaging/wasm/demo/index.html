ImaginaryMOS — WebAssembly demo

This page is the template shipped with the WebAssembly bundle. The ImaginaryMOS libraries build as static archives that you link into your own Emscripten module (see BUILDING.md); this page loads that module and drives a Profile 0 handshake against an NCS over the browser WebSocket API.

Point it at your NCS endpoint and open the console:

emcc app.cpp -I include lib/libimos.a lib/libimos_transports.a \
  lib/libimos_core.a -lwebsocket.js -o imos_demo.js
Load your compiled imos_demo.js below…
